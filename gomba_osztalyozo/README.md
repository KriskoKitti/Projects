# Gomba osztályozó

Ez a Python projekt gombák osztályozására készült KNN és döntési fa modellel.

## Futtatás

1. Klónozd a repository-t:
```bash
git clone https://github.com/felhasznalo/Projects.git
cd gomba_osztalyozo
```
2. Telepítsd a függőségeket:
```bash
pip install -r requirements.txt
```
3. Futtasd a predikciót:
```bash
python bigdata_beadando2.py
```
