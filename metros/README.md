# Metros Starter – JavaScript Web App

Egyszerű, böngészőben futó JavaScript alapú webalkalmazás, amely egy rácsos játéktéren metróvonalak építését valósítja meg előre definiált szabályok szerint.

## Technológiák
- HTML
- CSS
- JavaScript (ES6)
- JSON

## Funkciók
- Interaktív játéktér
- Adatok betöltése JSON fájlokból
- Eseménykezelés JavaScript segítségével
- Pontszámítás és játékmenet-kezelés

## Futtatás
A projekt lokális HTTP szerveren futtatható  
(pl. **VS Code Live Server**).
