# Budapesti Közösségi Költségvetés Webalkalmazás

Ez a projekt a Budapesti Közösségi Költségvetés digitális platformját valósítja meg. A rendszer lehetővé teszi a felhasználók számára, hogy projektek ötleteit leadják, szavazzanak rájuk, valamint az adminisztrátorok menedzselhessék a projekteket és statisztikákat tekintsenek meg.

## Fő funkciók

- **Projekt lista és részletek**: A közzétett projektek megtekinthetők, kategóriák szerint szűrhetők.  
- **Hitelesítés**: Regisztráció, bejelentkezés, kijelentkezés, admin jogosultság.  
- **Projekt leadás és státuszkezelés**: Új projektek leadása, admin általi jóváhagyás vagy visszautasítás.  
- **Szavazás**: Felhasználók kategóriánként legfeljebb 3 szavazatot adhatnak és a szavazatok visszavonhatók.
- **Admin statisztikák**: Legtöbb szavazatot kapó projektek, kategóriánkénti toplisták.  

## Technológiák

- **Backend**: PHP (keretrendszer nélkül)  
- **Frontend**: HTML, CSS
